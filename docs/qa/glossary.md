## Usage Rules

1. **Consistency**: Always use the "Approved" term. Do not mix alternatives in the same context.
2. **Capitalization**: Persian doesn't use capitalization, but proper nouns (system names, brands) keep English casing.
3. **Numbers**: Use Persian digits (۰-۹) in display; Latin digits (0-9) in code, IDs, SKUs.
4. **Dates**: Display in Jalali (Persian) calendar; store in Gregorian.
5. **Currency**: Display in Rial with Persian formatting (۷۰۰,۰۰۰,۰۰۰ ریال); store as integer Rial.
6. **Compound Terms**: Use space or zero-width joiner (ZWJ) appropriately: "حقِ مسکن" not "حق مسکن" for ezāfe.
7. **Technical Terms**: Keep English for API fields, database columns, code variables.
